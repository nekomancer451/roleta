Esta roleta foi criada para auxíliar em um sorteio que será feito pelo stand da Biblioteca da PGM na bienal 2025, 
pela falta de uma roleta que fosse offiline, otimizado para movile (visto que serão utilizados tablets institucionais)
personalizável quanto a quantidade de itens a serem sorteados entre 
outros detalhes. 
Assim, esse modelo de roleta básico funciona perfeitamente em dispositivos mobile, porém foi feito para ficar em posse
dos responsáveis pelo evento, por isso as configurações de administrador ficam na mesma página e no mesmo código, para
facilitar a configuração e manipulação.
Sinta-se livre para usá-lo, respeitando os créditos ao autor do código base.
